# Что такое Date?

Дата в js это число миллисекунд которое показывает сколько прошло с 1970 года 1 января. Оно не хранит готовое число по типу 01.01.1970 Он конвертирует все с миллисекунд. Но стоить помнить, Отсчёт у date начинается с 1970 года а не с 0.

## Как создать Date?

Есть 3 способа создания даты.

## 1. Создание через new Date()

Создает объект с текущей датой и временем

``` js
    const date = new Date();

    console.log(date); // (Mon Jun 01 2026 16:23:14 GMT+0500)
```
В данном примере js берет текущую дату из данных компьютера и засовывает его в объект

## 2. new Date(milliseconds)

Создает дату, добавляя указоное количество миллисекунд с 1970 года.

``` js
    const date = new Date(0);
    console.log(date); // (Thu Jan 01 1970) 
```
В примере просто вывело 1 год с которого начинается отсчет, поскольку в аргументах мы задали 0 миллисекунд. Вот другой пример:

``` js
    const date = new Date(86400000); // 86400000 это 1 день
    console.log(date); // (Thu Jan 02 1970) 
```

## 3. new Date(string)

Создает объект даты из строки

``` js
    const date = new Date("2026-04-01")

    console.log(date) // Mon Apr 01 2026
```

## 4. new Date(year, month, day, hour, minute, second, millisecond)

Создает дату из чисел 7 аргументов. Порядок очень важен

``` js
    const date = new Date(2020, 02, 10, 13, 36, 25, 0)
    console.log(date) // 10.02.2026 13:36:25
```

Важно знать в js месяцы начинаются с 0 как и дни недели.
